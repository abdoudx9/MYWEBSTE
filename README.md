# ABDOU DUXE Portfolio

موقع شخصي ثابت بتصميم أسود وأحمر، متجاوب مع الهاتف والحاسوب، ولا يحتاج إلى تسجيل دخول أو قاعدة بيانات.

## التشغيل
- افتح `index.html` في المتصفح للمعاينة.
- للنشر على GitHub Pages: ارفع الملفات الثلاثة (`index.html`, `style.css`, `script.js`) إلى جذر المستودع، ثم افتح Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.
- روابط YouTube وTelegram وGitHub موجودة في قسم التواصل ويمكن تعديلها من `index.html`.

## ملاحظات
- بطاقات المشاريع الحالية تعريفية فقط وتعرض "قريبًا"، وليست روابط لتطبيقات مكتملة.
- الموقع لا يجمع بيانات الزوار ولا يطلب تسجيل دخول.
